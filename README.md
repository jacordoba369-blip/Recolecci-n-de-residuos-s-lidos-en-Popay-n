Descripcion:
Este proyecto de ingeniería aplicada propone desarrollar un sistema web georreferenciado para que los habitantes de sectores seleccionados de la zona urbana de Popayán, Cauca, consulten los días y horarios de recolección de residuos sólidos por barrio o ubicación seleccionada
